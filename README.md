# AGROW Sentinel Backend

**AGROW Sentinel** — это распределенная IoT/AgroTech платформа в рамках экосистемы AGROW, предназначенная для комплексного точного земледелия, макро- и микро-скаутинга, а также автоматизированного мониторинга состояния сельскохозяйственных животных.

## Многоуровневая архитектура мониторинга

Система разделена на три ключевых эшелона сбора и обработки данных:

1. **Спутниковый эшелон (Макро-анализ):** Модуль интеграции с открытыми космическими снимками для вычисления вегетационных индексов (NDVI) и предиктивного обнаружения аномалий на больших площадях.
2. **Наземный эшелон (Микро-анализ):** Автономная сеть полевых датчиков на базе **ESP32 (MicroPython)**, измеряющая точные параметры почв в критических точках.
3. **Животноводческий эшелон (Telemetry):** Носимые IoT-устройства для отслеживания геопозиции, активности и базовых биометрик скота.

## Инфраструктура и Транспорт данных

* **Сетевой транспорт:** Гибридная топология **LoRa / Mesh** для передачи телеметрии в зонах полного отсутствия сотового покрытия.
* **Полевые шлюзы:** Edge-серверы на базе **Raspberry Pi**, осуществляющие первичную фильтрацию, агрегацию и буферизацию пакетов перед отправкой на центральный бэкенд.
* **Обратная связь (Actuators):** Поддержка удаленного управления периферией (например, включение LED-маяков на полевых контроллерах через мобильное приложение для локализации проблемных зон).

## Технологический стек бэкенда

* **Core:** Python (FastAPI), SQLAlchemy.
* **Storage:** PostgreSQL + **PostGIS** (строгая геопространственная валидация полей, треков животных и координат датчиков).
* **Broker:** **RabbitMQ** для построения асинхронной, отказоустойчивой распределенной архитектуры обработки потоковых IoT-данных.
